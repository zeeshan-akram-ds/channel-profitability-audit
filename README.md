# Channel Profitability Audit

Testing whether a channel's ROAS ranking actually matches its true profitability ranking, once profitability is measured as contribution margin after CAC, tracked over 3- and 6-month payback windows.

**Status: in progress.** This is a live analytical build, see `docs/` for the framing, data-source decisions, and running decision log as the project develops. Final report and full write-up land at the end.
